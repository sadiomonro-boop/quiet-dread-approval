A one-line code review comment that approves a pull request while carrying quiet existential dread: "LGTM. Merging before I remember why we were afraid to touch this file." Seventy characters, flat tone, no exclamation — the dread is in the approval itself, not bolted onto it. It reads like something a tired engineer would paste before clicking approve, and it avoids the stock lines already crowding the field.

## Run it

```sh
node main.ts
```

This writes the comment to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
